                    术语表 #

                    下面列出 IceFireDB 各产品中使用的主要术语。

                    Itemdescribe
                    NoSQL非关系型数据库（NoSQL），其数据以不同于关系表的形式存储。
                    LSM在计算机科学中，日志结构合并树（log-structured merge-tree，又称 LSM 树或 LSMT）是一种数据结构，其性能特征使它很适合为高插入量的文件（例如事务日志数据）提供带索引的访问。
                    OSS对象存储服务（Object Storage Service）
                    IPFS星际文件系统（The InterPlanetary File System，IPFS）是一种协议、超媒体和文件共享的点对点网络，用于在分布式文件系统中存储和共享数据。
                    P2P点对点（peer-to-peer）网络
                    EVM Smart contracts智能合约（smart contract）是一种计算机程序或交易协议，旨在按合同或协议的条款自动执行、控制或记录与法律相关的事件和动作。
                    CRDT在分布式计算中，无冲突复制数据类型（conflict-free replicated data type，CRDT）是一种在网络中多台计算机之间复制的数据结构，
                    RAFTRaft 是一种共识算法，其设计目标是易于理解。
                    IPLDIPLD 是 InterPlanetary Linked Data 的缩写；IPLD 是一套格式与数据结构的生态，用于构建可以完全去中心化的应用。
                    IPFS-LOGIPFS-log 是一种面向分布式系统的、不可变的、基于操作的、无冲突的复制数据结构（CRDT）。它是一份只追加日志，可用于为 p2p 应用中各对等节点之间的可变共享状态建模。
