                    IceFireDB-SQLProxy #

                    一个 MySQL 协议代理，它挡在普通 MySQL 服务器前面，把语句重放给网络中的其他代理节点，于是分布 在不同地方的多套 MySQL 实例无需改动应用就能保持一致。

                    cd IceFireDB-SQLProxy
make                                   # → bin/IceFireDB-SQLProxy
./bin/IceFireDB-SQLProxy -c ./config/config.yaml

mysql -h 127.0.0.1 -P 33306 -u host1 -p    # a user from userlist

                    它是什么 #

                    属性取值
                    协议MySQL 线上协议
                    后端MySQL（mysql.admin、mysql.readonly）
                    复制语句经 libp2p 在各代理节点之间传播
                    监听server.addr，默认 :33306
                    二进制bin/IceFireDB-SQLProxy（-c <config.yaml>）

                    配置（config/config.yaml） #

                    配置项含义文件中的默认值
                    server.addr协议代理监听地址":33306"
                    debug.enable / .port调试/pprof 服务器true / 17878
                    mysql.admin写连接池：addr、user、password、dbname、minAlive、maxAlive、maxIdle127.0.0.1:3306、admin_user
                    mysql.readonly读连接池，键名相同127.0.0.1:3306、readonly_user
                    userlist客户端租户（user/password）host1 / host1
                    p2p.enable网络复制true
                    p2p.serviceDiscoveryId会合名，必须与其他节点一致tanovo_sqlproxy_admin_service
                    p2p.serviceCommandTopic命令频道tanovo_sqlproxy_command_topic
                    p2p.adminTopic / p2p.readonlyTopic按角色划分的频道tanovo_sqlproxy_admin_topic / …_readonly_topic
                    p2p.serviceDiscoverModeadvertise 或 announceadvertise
                    p2p.nodeHostIp / nodeHostPort对等节点应当拨号的地址127.0.0.1 / 0

                    注意本组件用的是驼峰式键名（serviceDiscoveryId，而不是 PubSub/SQLite 里的 service_discovery_id）。 在组件之间照抄配置，会静默地给你一个默认值。

                    运维要点 #

                    • 读写分离是一个配置选择，不是路由魔法：读查询用 mysql.readonly 这个池，写入用 mysql.admin。 如果没有副本，把它们指向同一台服务器即可。
                    • 示例凭据（admin_pass、readonly_pass、host1/host1）都是占位值 —— 请替换掉。
                    • 语句会重放到每个代理节点，所以只能用确定性 SQL。NOW()/RAND()/UUID() 可能产生分歧。
                    • 没有冲突解决：网络按到达顺序排序，所以两个代理节点并发写同一行时，最终落在后应用的那条语句上。
                    • 示例配置里调试服务器是开启的，监听端口 17878；生产环境请关掉它。

                    什么时候用它 #

                    你已经在跑 MySQL，希望把同样的数据放到离其他地区用户更近的地方，又不想把应用迁到新数据库上。它不是 MySQL 集群的替代品：它不对 MySQL 后端做自动故障转移，也不为冲突写入保证跨站点一致性。
