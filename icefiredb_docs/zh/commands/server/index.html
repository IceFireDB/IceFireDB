                    服务器 #

                    数据面中的三条命令。运维需要的其他一切（RAFT、CLUSTER、MACHINE、BARRIER、AUTH、SHUTDOWN、VERSION）都在 系统命令中。

                    命令读写语法返回示例 → 回复
                    INFORINFObulk 多行报告INFO → # Server\r\nversion…
                    FLUSHALLWFLUSHALLinteger 删除键数FLUSHALL → (integer) 42
                    FLUSHDBWFLUSHDBinteger 删除键数 —— FLUSHALL 的别名FLUSHDB → (integer) 42

                    INFO 不接受参数 #

                    INFO memory、INFO server 和 INFO replication 都是参数错误；该命令的判断是 len(args) != 1 → wrong number of arguments。请直接请求 INFO，再从这一个回复里读你需要的分节。各分节及其字段记录在 可观测性中。

                    INFO 是读命令：接收请求的节点用自己的状态作答，永不复制。

                    FLUSHDB 就是 FLUSHALL #

                    引擎只有一个逻辑数据库，因此 FLUSHDB 实现为 FLUSHALL 的别名。两者都：

                    • 是写命令，因此经过 Raft 日志并被复制（这也是它们返回计数而不是 OK 的原因）；
                    • 删除每个按类型划分的键空间（string、hash、list、set、zset）中的每一个键，包括它们的过期时间；
                    • 不可恢复 —— 没有撤销，也没有软删除。请把它们当作等同于 root 的操作。
