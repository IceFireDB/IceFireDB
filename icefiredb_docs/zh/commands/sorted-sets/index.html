                    有序集合 #

                    15 条命令。分值类型是 64 位整数，不是双精度浮点 —— 这是唯一会改变查询结果、而不只是线格式的差异。

                    命令读写语法返回示例 → 回复
                    ZADDWZADD KEY score MEMBER [score MEMBER ...]integer 新增成员数ZADD board 100 ada 90 bob → 2
                    ZINCRBYR ⚠ZINCRBY KEY increment MEMBERbulk 新分值ZINCRBY board 5 ada → 105
                    ZREMWZREM KEY MEMBER [MEMBER ...]integer 删除成员数ZREM board bob → 1
                    ZCARDRZCARD KEYinteger 基数ZCARD board → 1
                    ZCOUNTRZCOUNT KEY min maxinteger 分值区间内的成员数ZCOUNT board 0 200 → 1
                    ZSCORERZSCORE KEY MEMBERbulk 分值，缺失为 nullZSCORE board ada → 105
                    ZRANKRZRANK KEY MEMBERinteger 升序排名（0 起），缺失为 nullZRANK board ada → 0
                    ZREVRANKRZREVRANK KEY MEMBERinteger 降序排名，缺失为 nullZREVRANK board ada → 0
                    ZRANGERZRANGE KEY start stop [WITHSCORES]array 成员（及分值）ZRANGE board 0 -1 WITHSCORES → [ada, 105]
                    ZREVRANGERZREVRANGE KEY start stop [WITHSCORES]array 成员（及分值）ZREVRANGE board 0 0 → [ada]
                    ZRANGEBYSCORERZRANGEBYSCORE KEY min max [WITHSCORES]array 成员（及分值）ZRANGEBYSCORE board 100 200 → [ada]
                    ZREVRANGEBYSCORERZREVRANGEBYSCORE KEY max min [WITHSCORES]array 成员（及分值）ZREVRANGEBYSCORE board 200 100 → [ada]
                    ZREMRANGEBYRANKR ⚠ZREMRANGEBYRANK KEY start stopinteger 删除成员数ZREMRANGEBYRANK board 0 0 → 1
                    ZREMRANGEBYSCORER ⚠ZREMRANGEBYSCORE KEY min maxinteger 删除成员数ZREMRANGEBYSCORE board 0 50 → 0
                    ZCLEARWZCLEAR KEYinteger 删除成员数ZCLEAR board → 1

                    说明 #

                    • ⚠ ZINCRBY、ZREMRANGEBYRANK 和 ZREMRANGEBYSCORE 被注册为读命令，尽管它们会修改数据。本地执行无害；在集群中它们的影响不会被复制，也无法在 leader 切换后存活。修复前：在客户端算好分值并用 ZADD 写入，用 ZREM 删除成员。
                    • 有序集合没有 TTL。 没有 ZEXPIRE/ZTTL；请清理并重建键（ZCLEAR），或把过期记账放在一个字符串键里。
                    • 分值按 int64 解析。像 1.5 这样的浮点分值会被拒绝；WITHSCORES 返回整数。
                    • ZRANGEBYSCORE min max 两端都是闭区间；ZREVRANGEBYSCORE max min 的参数顺序相反，与 Redis 一致。
                    • 成员缺失时，ZRANK/ZREVRANK 返回 null，ZSCORE 同理。
                    • 所有区间读取都按分值排序，分值相同时再按成员排序。
