                    说明 #

                    • SPOP 的抽取是跨副本确定性的。 由于它是写命令，结果必须在每个节点上一致，所以抽取的成员由 Raft 提供的种子决定，而不是 math/rand。带 count 时，count 会夹到集合大小；count = 0 返回空数组，负数 count 报错。
                    • SRANDMEMBER 是读命令，可以使用真正的随机性（count 为正时返回不重复的成员，为负时允许重复）。|count| 上限 1048576。
                    • SMOVE 移到同一个键是 no-op，返回 1 并保留 TTL。
                    • SCLEAR/SMCLEAR 删除整个集合及其过期时间；SREM 只删除成员。
                    • SPERSIST 是引擎中唯一的 *PERSIST 命令，且已知在 ipfs 后端会留下过期时间。字符串、哈希和列表根本没有 PERSIST。
                    • 集合代数命令读取参数中指定的集合；*STORE 变体会覆盖目标键，并返回结果大小。
