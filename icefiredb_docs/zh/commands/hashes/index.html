                    哈希 #

                    19 条命令。哈希键空间与同名键上的字符串键空间彼此独立。

                    命令读写语法返回示例 → 回复

                    说明 #

                    • HCLEAR / HMCLEAR 删除整条哈希（相当于该类型的 DEL），并连带删掉它的过期时间；HDEL 只删除单个字段。
                    • 没有 HPERSIST —— 处理器存在但未注册。
                    • HSET 只统计新建的字段；覆盖已有字段计 0。
                    • HGETALL 按存储层的迭代顺序返回字段/值对。不要依赖它的顺序 —— 如果顺序重要，请在客户端排序。
                    • 对值为空的字段执行 HGET：本地后端返回空 bulk string，去中心化后端返回 null —— 在去中心化后端上这两种状态无法区分。见 兼容性。
                    • 字段缺失或值为空时，HSTRLEN 都报 0。
                    • 过期：HEXPIRE/HEXPIREAT/HTTL 作用于哈希，与同名键上的字符串互不影响。
