                    记法 #

                    记法含义
                    KEY二进制安全的键名，最大 1024 字节（ledis MaxKeySize；空键会被拒绝）
                    VALUE二进制安全的值，最大 1 GiB（MaxValueSize）
                    [ARG]可选参数
                    ARG...一个或多个
                    A | B二选一
                    R / W读命令（本地执行）/ 写命令（经 Raft 日志复制）
                    integerRESP 整数 :1
                    bulkRESP bulk string $3 foo
                    nullRESP 空批量 $-1，表示“不存在”
                    arrayRESP 数组 *2 …
                    +OKRESP 简单字符串

                    适用于所有命令的规则 #

                    1. 每种数据类型一个独立键空间。 同一个键可以同时持有字符串和哈希和列表。类型不符的命令会在该类型自己的（可能为空的）视图上执行，而不是返回 WRONGTYPE。见 兼容性。
                    2. 过期时间按类型分开。 EXPIRE/TTL 作用于字符串；HEXPIRE/HTTL 作用于哈希；LEXPIRE/LTTL 作用于列表；SEXPIRE/STTL/SPERSIST 作用于集合。有序集合没有 TTL 命令。TTL 为整秒；-1 表示“无过期”，已过期的键报的也是 -1。
                    3. 分值是 64 位整数，不是浮点数。
                    4. 数量与分页都有上限。 COUNT 上限 10000，SRANDMEMBER 的 |count| 上限 1048576。
                    5. 写命令会在每个副本上重放，结果必须全集群一致 —— 这正是 SPOP 采用确定性抽取的原因。
                    6. 错误以 RESP 错误返回（-ERR …）。永远不会产生 -WRONGTYPE。不允许提供读的从节点会返回 -MOVED（带 --try-errors 时为 -TRY）。

                    读写分类，以及为什么重要 #

                    R 表示处理器通过 conf.AddReadCommand 注册：它在接收请求的节点上执行，针对的是该节点已应用的状态。W 表示 conf.AddWriteCommand：它经 Raft 日志串行化，并在每个节点上应用。

                    有三条有序集合命令虽然会修改数据，却被注册为读命令：

                    命令注册为集群中的影响
                    ZINCRBYR只修改本地节点 —— 不复制，leader 切换后丢失
                    ZREMRANGEBYRANKR同上
                    ZREMRANGEBYSCORER同上

                    在这一点改变之前，请用 ZADD 写入算好的分值，用 ZREM 删除成员。

                    回复类型 #

                    处理器返回 Go 值，由 RESP 层直接映射：

                    处理器返回客户端看到
                    nil空批量（$-1）
                    []bytebulk string
                    [][]byte、[]string数组
                    redcon.SimpleString简单字符串（+OK）
                    redcon.SimpleInt、int64整数
                    error错误回复（-ERR …）

                    简单字符串不能携带 \r\n，所以值永远不会以简单字符串返回。

                    限额 #

                    限制项取值
                    键大小1024 字节（ledis.MaxKeySize）；空键会被拒绝
                    哈希字段 / 集合成员 / zset 成员各 1024 字节
                    值大小1 GiB（ledis.MaxValueSize）
                    任意 scan 的 COUNT10000，超出即夹到上限；仍只是提示
                    SRANDMEMBER / SPOP 计数绝对值 ≤ 1048576；SPOP 夹到集合大小
                    过期时间整秒；PX 向上取整；无法表示的 EX 直接报错
                    数据库数量1（未实现 SELECT）
                    阻塞命令无（BLPOP/BRPOP 未注册）
