                    说明 #

                    • SET 会清掉已有的过期时间，除非给出 KEEPTTL。PX 会向上取整到下一秒，因为过期时间按整秒存储，所以 PX 500 让键保留 1 秒、PX 1500 保留 2 秒 —— 绝不会少于请求值。
                    • 条件阻止写入时，SET ... NX/XX 返回 null bulk，而不是错误。
                    • 字符串没有 PERSIST：处理器虽然存在，但被注释掉了、未注册。想保留值又改变生命周期，请再次 EXPIRE，或使用 SET … KEEPTTL。
                    • EXISTS 只统计字符串键空间中的键，看不到同名的哈希。其他类型请用 HKEYEXISTS、LKEYEXISTS、SKEYEXISTS。
                    • DEL 删除这些键上的字符串，而不是同名的哈希/列表/集合。
                    • 对非数值执行 INCR/DECR 会像 Redis 一样返回 -ERR；缺失的键按 0 处理。
                    • BITCOUNT/BITPOS 支持 Redis 7 的可选 BYTE/BIT 单位。
                    • 过期时间计算使用 Raft 时钟，因此当某个节点的 Raft 时钟落后于本地时钟时，较短的 TTL 可能被拒绝。见 兼容性。
                    • TTL 由存储层按本地墙上时钟计算，因此各副本报告的值可能相差各自的 apply 延迟。
