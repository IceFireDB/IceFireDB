                    IceFireDB-Redis-Proxy #

                    一个挡在 Redis（单节点或集群）前面的 RESP 协议代理，它把命令重放给网络中的其他代理节点。已有的 Redis 应用不必换数据库，就能获得多站点同步。

                    cd IceFireDB-Redis-Proxy
make                                   # → bin/IceFireDB-Redis-Proxy
./bin/IceFireDB-Redis-Proxy -c ./config/config.yaml

redis-cli -p 16379 SET k v

                    它是什么 #

                    属性取值
                    协议两侧都是 Redis RESP
                    后端redisdb.type：node 或 cluster，redisdb.start_nodes
                    复制命令经 libp2p 在各代理节点之间传播
                    监听proxy.local_port，默认 16379
                    二进制bin/IceFireDB-Redis-Proxy（-c <config.yaml>）

                    配置（config/config.yaml） #

                    配置项含义文件中的默认值
                    proxy.local_portRESP 监听端口16379
                    proxy.enable_mtls协议代理监听端的双向 TLSfalse
                    redisdb.typenode 或 clusternode
                    redisdb.start_nodes逗号分隔的后端地址127.0.0.1:6379
                    redisdb.conn_timeout / conn_read_timeout / conn_write_timeout / conn_alive_timeout秒5 / 1 / 1 / 60
                    redisdb.conn_pool_size后端连接数（0 表示短连接）80
                    p2p.enable、service_discovery_id、service_command_topic、service_discover_mode、node_host_ip、node_host_port网络设置形态与 PubSub 相同
                    pprof_debug.enable / .portpprof 服务器true / 16060
                    log.level日志级别debug
                    ip_white_list.enable / .list客户端白名单true / 回环地址
                    cache.enable / .max_items_size / .default_expiration（毫秒）/ .cleanup_interval（秒）协议代理缓存true / 2048 / 5000 / 120
                    ignore_cmd.enable / .cmd_list要丢弃的命令false / []

                    运维要点 #

                    • 在客户端连接之前，redisdb.start_nodes 必须指向一个可达的后端；协议代理不是数据库，自己没有 存储。
                    • 命令会在对等节点上重放：非确定性的命令（SPOP、INCRBYFLOAT、任何使用服务器时间的命令、 用了 math.random 的 EVAL）会在不同站点之间产生分歧。请尽量使用确定性操作，或者把这些键留在 同一个站点。
                    • 后端前面的缓存默认开启，过期时间为 5 秒 —— 从另一个客户端做写后读，最多可能读到这么久的旧数据。 当你需要严格读时，请关闭 cache.enable。
                    • 示例配置里 pprof_debug 是开着的（16060）；在开发环境之外请禁用它。
                    • 与 PubSub 相同的发现 id 注意事项：两个部署使用同一个 id 就会共享一个网络。

                    协议代理还是引擎？ #

                    需求选择
                    保留现有 Redis，加上多站点同步IceFireDB-Redis-Proxy
                    用 Raft 复制、可插拔存储的引擎替换 RedisNoSQL 引擎
                    只需要消息扇出IceFireDB-PubSub
