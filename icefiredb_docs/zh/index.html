                    IceFireDB 文档 #

                    IceFireDB 是面向 web2 与 web3 的去中心化数据库基础设施。本站记录的是你可以从本仓库构建出来的 引擎 —— IceFireDB NoSQL 引擎：一个兼容 Redis（RESP 协议）的服务器，它在可插拔的 KV 存储层 之前放置一份经 Raft 复制的命令日志，并在同一套接口之后提供可选的 P2P 驱动（CRDT、IPFS、 IPFS-log、OSS）。

                    当前版本： 1.0.0-rc.1 · 协议： RESP（Redis 客户端无需改动即可使用） · 许可证： Apache 2.0
