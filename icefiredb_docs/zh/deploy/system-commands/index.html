                    系统命令 #

                    命令参考里的 110 条命令是数据面。在它们之下还有第二个面，由 Raft/RESP 层提供，运维 依赖它。它不属于 Redis 命令集，所以记在这里。

                    这些命令除非特别说明，否则都不经过 Raft 日志，并且 --try-errors 会禁用 CLUSTER 家族。

                    连接 #

                    命令回复说明
                    PING [message]PONG，或该 message在分发之前处理
                    ECHO message该 message—
                    AUTH tokenOK / -unauthorized设置 --auth 时必须最先发送
                    QUITOK，然后连接关闭—
                    SHUTDOWN（无——进程退出）从客户端角度看等价于 SIGKILL；配置了 AUTH 时要求先认证

                    Machine #

                    命令回复含义
                    VERSIONbulk string引擎版本，例如 1.0.0-rc.1
                    MACHINEnow、uptime、boottime 的映射（纳秒）时间来自 Raft 时钟，所以每个节点一致
                    MACHINE HUMAN同样的键，RFC3339 / duration 形式人类可读的变体
                    BARRIEROK一个空操作的写：它返回时，该客户端此前发出的每个写都已应用

                    BARRIER 是跨客户端或跨节点获得读己之写（read-your-writes）保证的方式：在主节点上发送 BARRIER， 然后用 --openreads 在从节点上读。

                    RAFT #

                    命令回复含义
                    RAFT HELP命令列表—
                    RAFT LEADER地址当前主节点的 advertise 地址
                    RAFT INFO [pattern]状态映射Raft 状态、任期、已应用/已提交索引、主节点、对等节点
                    RAFT SERVER LISTid、address、leader 的数组集群成员
                    RAFT SERVER ADD id address1添加（或提升）一个投票者；address 是其他节点拨号的地址
                    RAFT SERVER REMOVE id1移除一个成员
                    RAFT SNAPSHOT NOW快照 id立即做一次快照
                    RAFT SNAPSHOT LISTid/size 数组本节点上的快照
                    RAFT SNAPSHOT FILE id绝对路径快照文件在服务端的位置
                    RAFT SNAPSHOT READ id [RANGE offset limit]bulk 字节读该文件，整体读或按窗口读
                    redis-cli -p 11001 RAFT SERVER LIST
1) 1) "id"
   2) "1"
   3) "address"
   4) "127.0.0.1:11001"
   5) "leader"
   6) "true"
...

redis-cli -p 11001 RAFT SERVER ADD 4 10.0.0.14:11001
redis-cli -p 11001 RAFT SERVER REMOVE 4

                    成员操作只在主节点上成功；在从节点上会以通常的重定向错误失败。

                    CLUSTER #

                    Redis Cluster 形状的内省，好让集群感知的客户端和代理能发现拓扑：

                    命令回复含义
                    CLUSTER INFO多行字符串cluster_state:ok|fail、cluster_known_nodes、cluster_size……
                    CLUSTER NODES多行字符串每个成员一行：id、host:port@port、角色（master/slave）、主节点 id、connected、槽
                    CLUSTER SLOTS数组一个覆盖 0-16383 指向主节点的范围

                    整个键空间在主节点上报告为单个槽范围，因为没有分片。这些命令的意义是兼容性而不是分布——在一个主节点 上看到 0-16383 的客户端行为是正确的，而且每个节点本来就持有每个键。

                    TICK（内部） #

                    TICK <timestamp> <seed> 注册为写命令，通过日志复制，由引擎自己用来推进机器时钟和随机种子。处理器 会拒绝格式错误的调用，但客户端没有理由发送它：Raft 层在每个 tick 间隔（默认 200 ms）注入一个，正是 它让 m.Now() 和 m.Rand() 在各副本之间保持一致。写命令必须使用这两个函数而不是 time.Now()/math/rand，原因正在于此——见仓库中的 COMMAND-AUDIT.md。

                    安全地使用管理面 #

                    • 把管理命令包进你自己的工具里；它们接受真实参数（RAFT SERVER REMOVE <id> 是破坏性的），并且没有 确认步骤。
                    • 设置 --try-errors 时 CLUSTER 会消失，所以不要为需要该参数的部署在它上面构建自动化。
                    • 这个面只由共享的 --auth token 保护。见 安全。
