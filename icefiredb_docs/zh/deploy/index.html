                    部署

                    部署 #

                    在生产环境运行 NoSQL 引擎所需的全部内容，按你会用到的顺序排列：

                    页面它回答的问题
                    配置有哪些 flag、默认值是什么、哪些是不起作用的？
                    集群Raft 集群如何工作；如何添加／移除／替换节点？
                    存储驱动该选哪个驱动；每个驱动保证什么？
                    安全TLS、集群认证令牌，以及哪些东西没有被保护。
                    可观测性/healthz、/readyz、/metrics、INFO 各节、pprof。
                    运维备份、恢复、滚动升级、灾难恢复。
                    系统命令RAFT …、CLUSTER …、MACHINE、BARRIER、TICK、AUTH。

                    有两条性质贯穿全部内容，值得在这里说一次：

                    • 每个节点一个数据目录。 存储驱动、Raft 日志与快照都位于 <data-dir>/IceFireDB/<node-id>/ 之下。复制该目录就是一个自洽的备份原语；在已有目录上更换存储 驱动则不受支持。
                    • 管理接口面需要显式开启，且绑定在回环地址。 --metrics 与 --pprof 默认关闭，启用后若不额外 传入地址，它们监听 127.0.0.1。
