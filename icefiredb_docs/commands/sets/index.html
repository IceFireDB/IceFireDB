                    Notes #

                    • SPOP is deterministic across replicas. Because it is a write command, its result must be identical on every node, so the picked member is derived from the Raft-seeded state rather than math/rand. With count, the count is clamped to the set size; count = 0 answers an empty array and a negative count is an error.
                    • SRANDMEMBER is a read command and may use real randomness (count distinct members when positive, repeats when negative). |count| is capped at 1048576.
                    • SMOVE to the same key is a no-op that returns 1 and keeps the TTL.
                    • SCLEAR/SMCLEAR delete whole sets and their expiration; SREM removes members.
                    • SPERSIST is the only *PERSIST command in the engine, and it is known to leave the expiration in place on the ipfs backend. Strings, hashes and lists have no PERSIST at all.
                    • Set algebra commands read the sets named in the arguments; *STORE variants overwrite the destination and return the size of the result.
