                    Notes #

                    • HCLEAR / HMCLEAR delete the whole hash (like DEL for this type) and take its expiration with it; HDEL removes individual fields.
                    • There is no HPERSIST — the handler exists but is not registered.
                    • HSET counts only newly created fields; overwriting an existing field counts 0.
                    • HGETALL answers field/value pairs in the storage’s iteration order. Do not rely on it for ordering — sort client-side if it matters.
                    • HGET of a field whose value is empty answers an empty bulk string on the local backends and null on the decentralized ones — the two states are not distinguishable there. See Compatibility.
                    • HSTRLEN reports 0 both for a missing field and for an empty one.
                    • Expiry: HEXPIRE/HEXPIREAT/HTTL act on the hash, independently of any string at the same key.
