# IceFireDB NoSQL — Production-Readiness (1.0.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the confirmed P0 production blockers in the IceFireDB NoSQL core (root module) so that snapshot/restore works on every advertised storage backend, corrupt encrypted data can no longer crash a node, encryption uses sound nonces, and the profiling port is not exposed by default — then mark the build with an honest pre-1.0 version.

**Architecture:** The NoSQL core runs Redis RESP commands through a Raft log (`tidwall/uhaha`) into `ledisdb`, which persists to a pluggable storage driver implementing `github.com/ledisdb/ledisdb/store/driver.IDB`. Today `snapshot()`/`restore()` in `main.go` bypass that interface and operate on a global `*leveldb.DB`, which is only ever set for leveldb-family backends — so badger/ipfs/oss snapshots hit a nil pointer. The fix re-routes snapshot/restore through the `driver.IDB` abstraction (`NewSnapshot`/`NewIterator`/`NewWriteBatch`), which all backends already implement, removing the leveldb coupling entirely.

**Tech Stack:** Go 1.25 (vendored deps), ledisdb, goleveldb, badger v4, `tidwall/uhaha`, `tidwall/sds` (snapshot stream encoding), `crypto/aes` + `crypto/cipher` (GCM).

**Scope note:** This plan covers **only the P0 blockers** — the concrete, code-level defects that gate a trustworthy 1.0.0. The P1 (reliability/correctness test suites, cluster/chaos testing, Redis-compatibility suite) and P2 (auth/ACL, health endpoints, metrics, repo hygiene) workstreams are independent subsystems and each deserves its own plan; they are outlined at the end of this document as follow-on plans, not implemented here.

Create `snapshot.go`:

```go
package main

import (
	"io"

	"github.com/ledisdb/ledisdb/store/driver"
	"github.com/tidwall/sds"
)

// restoreBatchSize bounds how many key/value pairs accumulate before a flush
// during restore, keeping memory bounded on large snapshots.
const restoreBatchSize = 1000

// writeSnapshot serializes every key/value pair visible in the snapshot to wr
// using the sds stream format. It is backend-agnostic: any driver.ISnapshot works.
func writeSnapshot(s driver.ISnapshot, wr io.Writer) error {
	sw := sds.NewWriter(wr)
	it := s.NewIterator()
	defer it.Close()
	for it.First(); it.Valid(); it.Next() {
		if err := sw.WriteBytes(it.Key()); err != nil {
			return err
		}
		if err := sw.WriteBytes(it.Value()); err != nil {
			return err
		}
	}
	return sw.Flush()
}

// restoreSnapshot reads an sds stream produced by writeSnapshot and writes it
// into d in bounded batches. After each Commit the batch is reset via Rollback
// so it can be reused safely across both goleveldb and badger write batches.
func restoreSnapshot(d driver.IDB, rd io.Reader) error {
	sr := sds.NewReader(rd)
	wb := d.NewWriteBatch()
	defer wb.Close()

	n := 0
	for {
		key, err := sr.ReadBytes()
		if err != nil {
			if err == io.EOF {
				break
			}
			return err
		}
		value, err := sr.ReadBytes()
		if err != nil {
			return err
		}
		wb.Put(key, value)
		n++
		if n >= restoreBatchSize {
			if err := wb.Commit(); err != nil {
				return err
			}
			if err := wb.Rollback(); err != nil { // resets the batch for reuse
				return err
			}
			n = 0
		}
	}
	if n > 0 {
		return wb.Commit()
	}
	return nil
}
```

```go
package ipfs_synckv

import (
	"crypto/aes"
	"crypto/cipher"
	"crypto/rand"
	"errors"
)

var errCiphertextTooShort = errors.New("ipfs-synckv: ciphertext shorter than nonce")

func newGCM(key []byte) (cipher.AEAD, error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, err
	}
	return cipher.NewGCM(block)
}

func encrypt(data []byte, key []byte) ([]byte, error) {
	gcm, err := newGCM(key)
	if err != nil {
		return nil, err
	}
	nonce := make([]byte, gcm.NonceSize())
	if _, err := rand.Read(nonce); err != nil {
		return nil, err
	}
	return gcm.Seal(nonce, nonce, data, nil), nil
}

func decrypt(data []byte, key []byte) ([]byte, error) {
	gcm, err := newGCM(key)
	if err != nil {
		return nil, err
	}
	nonceSize := gcm.NonceSize()
	if len(data) < nonceSize {
		return nil, errCiphertextTooShort
	}
	nonce, cipherText := data[:nonceSize], data[nonceSize:]
	return gcm.Open(nil, nonce, cipherText, nil)
}
```
